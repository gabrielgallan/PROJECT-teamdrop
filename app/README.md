# TeamDrop App

A lightweight desktop widget built with React, TypeScript, and Tauri. Designed for quick file sharing within teams, invitation management, temporary sharing links, QR code generation, and real-time file updates.

## Getting Started

```bash
# 1. Navigate to the app directory
cd app

# 2. Install dependencies
pnpm install
```

### Development

```bash
pnpm tauri dev
```

### Production Build

```bash
pnpm tauri build
```
